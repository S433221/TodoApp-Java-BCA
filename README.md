# 📝 Java To-Do App - BCA Mini Project

A simple, console-based To-Do List Manager built using pure Core Java. No database, no frameworks - just pure logic.

![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=java&logoColor=white)
![BCA Project](https://img.shields.io/badge/BCA-Mini%20Project-blue)

## 🚀 Features
- ✅ Add new tasks
- 👀 View all tasks
- 🗑️ Delete task by number
- 📅 Auto Date with `LocalDate.now()`
- 🔁 Menu-driven infinite loop until Exit

## 🛠️ Tech Stack
- **Language:** Java (Core Java)
- **Concepts Used:** ArrayList, Scanner, Loops, LocalDate, OOP Basics
- **Bug Fixed:** Solved classic `nextInt()` vs `nextLine()` Scanner issue
